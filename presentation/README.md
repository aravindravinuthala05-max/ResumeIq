## How to present

Open the PowerPoint in Microsoft PowerPoint and use Presenter View so that the concise speaker notes are visible only to the presenter. The deck is designed for a professional B.Tech final-year project presentation.

## Recommended duration

12–15 minutes, followed by questions and a short application demonstration.
